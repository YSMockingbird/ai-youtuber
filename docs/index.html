AI YouTuber Local Controller

AI YouTuber Local Controllerは、所有者本人がMac上で使用する個人用の AI YouTuber配信管理ツールです。

主な機能

  • YouTube Liveの配信枠の作成・更新・開始・終了
  • YouTube Liveコメントの取得とAIによる返信
  • 配信予定、字幕、コメント表示、OBSの制御
  • 音声合成およびVRMキャラクターの表情・モーション制御

Google・YouTubeデータの利用目的

YouTube Data APIを使用して、所有者本人のYouTubeチャンネルにあるライブ配信と ライブコメントを管理します。取得した情報はAI YouTuber配信の運営にのみ使用し、 広告配信、販売、第三者向けの利用には使用しません。

運用形態

アプリ本体と認証情報は所有者のローカルMac上で動作・保存されます。 一般利用者向けのログイン機能やサービス提供は行っていません。

English

AI YouTuber Local Controller is a personal, locally operated tool used by its owner to manage AI YouTuber live streams on YouTube. It uses the YouTube Data API to create, update, start and stop live broadcasts, and to retrieve live chat messages for on-stream responses and display. The application and its OAuth credentials are operated and stored on the owner's local Mac. It is not offered as a login service or application for the public.
